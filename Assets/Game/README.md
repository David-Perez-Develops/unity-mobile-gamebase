# Game

All concrete gameplay for a project created from this Starter Kit belongs under this directory.

Suggested layout:

- `Scripts/`
- `Scenes/`
- `Prefabs/`
- `Art/`
- `Audio/`
- `Config/`

Game code may use Starter Kit services. Starter Kit code must not reference concrete Game types.

Reusable gameplay mechanics should only be extracted into a package/module after they prove reusable in a real game; do not pre-design gameplay as a plugin system.
